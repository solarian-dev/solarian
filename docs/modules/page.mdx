# Modules

Modules are the physical components of a robot module, encapsulating its bodies, 
joints, actuators and sensors.

It is instantiated during the initialization of a Robot, using configuration data 
to dynamically create and store sensor and actuator components based on the provided ModuleConfig.

Modules can be reused to create multiple instances of the same module on the same or 
different robots.

A typical module would be a robot arm, robot leg, robot base, etc.


## Creating a Module

To create a module, you need to subclass the Module class and define the actuators and sensors.

```python
from solarian.core.module import Module
from solarian_feetech.actuator import FeetechServo

class MyArmModule(Module):
    shoulder_pan = FeetechServo()
    shoulder_lift = FeetechServo()
    elbow_flex = FeetechServo()
    wrist_flex = FeetechServo()
    wrist_roll = FeetechServo()
```
