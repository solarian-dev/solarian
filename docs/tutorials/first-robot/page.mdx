# Your first Solarian robot

By the end of this tutorial you have a simulated robot: a six-joint arm you wrote yourself, a gripper installed from a plugin, and a wrist camera whose picture shows up in the controller. You move it with the keyboard. No hardware yet. {{ className: 'lead' }}

<CompleteRobotFigure />

The project is called `my_robot`, and every later tutorial continues it. Do the chapters in order. Each one ends with something you can see.

## Before you start

Finish [Installation](/docs/installation), including the simulation extra. From an editable checkout, add the extra in the cloned repository so the install stays editable:

<CodeGroup>

```bash {{ title: 'pip' }}
pip install "solarian[sim]"
```

```bash {{ title: 'editable / from source' }}
# In the cloned solarian repository
pip install -e ".[sim]"
```

</CodeGroup>

Check the two commands exist:

```bash
solarian --help
create-solarian --help
```

`solarian --help` should print a command list. `create-solarian --help` should print the scaffolder's usage. If either command is missing, the install did not put scripts on your `PATH`.

## What you will add, and in which order

1. An empty project, and a tour of the files. [Create a project](/docs/tutorials/first-robot/project).
2. The robot and its first module, the arm: six joints, a config file, a MuJoCo model in a scene. [The Robot](/docs/tutorials/first-robot/arm).
3. The messages between robot and controller. [Observations & Actions](/docs/tutorials/first-robot/observations-actions).
4. A controller you drive with the keyboard. [The Controller](/docs/tutorials/first-robot/keyboard).
5. The sim window, and the arm actually moving. [Move it](/docs/tutorials/first-robot/simulate).
6. A gripper from a plugin, mounted on the flange. [The gripper](/docs/tutorials/first-robot/gripper).
7. A camera, and its picture in the controller. [The camera](/docs/tutorials/first-robot/camera).

Three ideas are worth having before the first command. A **module** is one device (arm, gripper, camera). A **plugin** is a package that ships a module or a driver you did not write. The **three processes** — relay server, robot, controller — are how a Solarian app runs, even when all three are on your laptop. [Tutorial 1](/docs/tutorials/gentle-intro-to-robotics) is the longer version of the robotics words.

You will keep three terminals open for the rest of the course. Get used to restarting the robot and the controller after a code change. The server can stay up.
