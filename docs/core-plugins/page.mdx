# Core Plugins

These are the official plugins most projects start from. Each name links to its page in the [Plugin Directory](/plugins). Install one with [`solarian install`](/docs/using-plugins#install-a-plugin). {{ className: 'lead' }}

## Actuators

- [solarian-feetech](/plugins/solarian-feetech) — Feetech servos (STS3215, SCS) and the bus that talks to them, plus a `feetech-set-id` command.
- [solarian-dynamixel](/plugins/solarian-dynamixel) — Dynamixel servos (XL330, XM430, and the rest) and the DynamixelBus.
- [solarian-robstride](/plugins/solarian-robstride) — Robstride actuators and the bus that drives them.

## Arms and grippers

- [solarian-ur5](/plugins/solarian-ur5) — Universal Robots UR5 arm module, in joint space and Cartesian space.
- [solarian-so106](/plugins/solarian-so106) — SO-106 follower arm module.
- [solarian-umi-slim](/plugins/solarian-umi-slim) — UMI slim gripper module, including the MuJoCo model used in simulation.

## Skills and policies

- [solarian-move-skill](/plugins/solarian-move-skill) — Move to a named pose. Poses live in `conf/move.yaml`; add one there and start the skill with that name.
- [solarian-skill-cup-arrange](/plugins/solarian-skill-cup-arrange) — A UMI diffusion-policy skill, discovered through `solarian.skills`.
- [solarian-policy-diffusion](/plugins/solarian-policy-diffusion) — Trains and serves the diffusion policy that cup-arrange calls.
