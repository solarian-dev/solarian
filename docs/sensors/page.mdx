# Sensors

Sensor is a base class for hardware input components in robotic systems. It defines 
a standardized interface for reading sensor data from physical devices like cameras, 
encoders or lidars.

A sensor is typically attached to a body or a joint, and it is used to measure 
various physical quantities such as position, velocity, acceleration, or 
electrical signals. It can also be a camera, lidar, or any other sensor that 
measures physical quantities.
