# Quickstart

The following is a guide on how to install and run a solarian project.


## Installation

### Create a conda environment:

```bash
conda create -n solarian python=3.10
```

### Activate the environment:

```bash
conda activate solarian
```

### Install FFmpeg

```bash
conda install ffmpeg=7.1.1 -c conda-forge
```

### Clone Solarian repository

```bash
git clone https://github.com/solarian-dev/solarian.git
cd solarian
```

### Install dependencies:

With pip:

```bash
pip install -e .
```

With uv (faster; use the same conda env):

```bash
# Install uv once: curl -LsSf https://astral.sh/uv/install.sh | sh
conda activate solarian   # or your env name
uv pip install -e .
```

uv uses whichever Python is active, so packages are installed into your conda env.



### macOS (Darwin) on Apple Silicon (arm64)

You will need to install separate extra requirements to install atomics library from source:

```bash
pip install -r requirements-macos-arm64.txt
```

### Install xformers

```bash
pip install xformers==0.0.31.post1
```

## Running

### Running server

Within your project directory, run the following command:

```bash
solarian run-server
```

You can configure to run the server in a different machine by setting the `ip` parameter in the `conf/connection/localhost.yaml` file.

### Running robot

Within your project directory, run the following command:

```bash
solarian run-robot
```

### Running controller

Within your project directory, run the following command:

```bash
solarian run-controller
```

## Choose your client

Before making your first API request, you need to pick which API client you will use. In addition to good ol' cURL HTTP requests, Solariancol offers clients for JavaScript, Python, and PHP. In the following example, you can see how to install each client.

<CodeGroup>

```bash {{ title: 'cURL' }}
# cURL is most likely already installed on your machine
curl --version
```

```bash {{ language: 'js' }}
# Install the Solariancol JavaScript SDK
npm install @example/protocol-api --save
```

```bash {{ language: 'python' }}
# Install the Solariancol Python SDK
pip install protocol_api
```

```bash {{ language: 'php' }}
# Install the Solariancol PHP SDK
composer require protocol/sdk
```

</CodeGroup>

## Making your first API request

After picking your preferred client, you are ready to make your first call to the Solariancol API. Below, you can see how to send a GET request to the Conversations endpoint to get a list of all your conversations. In the cURL example, results are limited to ten conversations, the default page length for each client.

<CodeGroup tag="GET" label="/v1/conversations">

```bash {{ title: 'cURL' }}
curl -G https://api.protocol.chat/v1/conversations \
  -H "Authorization: Bearer {token}" \
  -d limit=10
```

```js
import ApiClient from '@example/protocol-api'

const client = new ApiClient(token)

await client.conversations.list()
```

```python
from protocol_api import ApiClient

client = ApiClient(token)

client.conversations.list()
```

```php
$client = new \Solariancol\ApiClient($token);

$client->conversations->list();
```
