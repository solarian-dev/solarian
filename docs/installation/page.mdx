# Installation

Solarian targets **Python 3.10+**. The recommended setup uses a [conda](https://docs.conda.io/) environment for isolation and either `pip` or [`uv`](https://docs.astral.sh/uv/) for installing packages.

<Note>
  Solarian uses [ZeroMQ](https://zeromq.org/) for networking, [Hydra](https://hydra.cc/) for configuration, and [PyTorch](https://pytorch.org/) (optional) for AI workloads. The base install gives you everything except the AI and simulation extras.
</Note>

## 1. Create a Python environment

<CodeGroup>

```bash {{ title: 'conda' }}
conda create -n solarian python=3.10
conda activate solarian
```

```bash {{ title: 'venv' }}
python3.10 -m venv .venv
source .venv/bin/activate
```

</CodeGroup>

## 2. Install FFmpeg

FFmpeg is required for video encoding (recording, dataset conversion). Install it once via conda or your system package manager:

<CodeGroup>

```bash {{ title: 'conda' }}
conda install ffmpeg=7.1.1 -c conda-forge
```

```bash {{ title: 'apt (Ubuntu/Debian)' }}
sudo apt-get install ffmpeg
```

```bash {{ title: 'brew (macOS)' }}
brew install ffmpeg
```

</CodeGroup>

## 3. Install Solarian

The fastest path is to install from PyPI. To hack on Solarian itself, clone the repository and use an editable install.

<CodeGroup>

```bash {{ title: 'pip' }}
pip install solarian
```

```bash {{ title: 'uv (faster)' }}
# Install uv once: curl -LsSf https://astral.sh/uv/install.sh | sh
uv pip install solarian
```

```bash {{ title: 'editable / from source' }}
git clone https://github.com/solarian-dev/solarian.git
cd solarian
pip install -e .
```

</CodeGroup>

After installation you should have two scripts on your `PATH`:

```bash
solarian --help          # main CLI
create-solarian --help   # project scaffolder
```

## 4. (Optional) Install extras

Solarian ships three optional dependency groups:

<CodeGroup>

```bash {{ title: 'AI (PyTorch + datasets)' }}
pip install "solarian[ai]"
```

```bash {{ title: 'Simulation (MuJoCo)' }}
pip install "solarian[sim]"
```

```bash {{ title: 'Everything' }}
pip install "solarian[all]"
```

</CodeGroup>

The `ai` extra installs PyTorch, torchvision, datasets, openai, and Weights & Biases. On Apple Silicon it also builds `xformers`. The `sim` extra installs gymnasium, MuJoCo, and dm_control.

## Platform-specific notes

### macOS on Apple Silicon (arm64)

`pip` and `uv` build `atomics` from source on Apple Silicon. The wheels on PyPI install and then fail at `dlopen`. Installing the `ai` extra also builds `xformers` against the pinned PyTorch. There is no macOS wheel, and the default source build passes `-fopenmp`, which Apple clang rejects, so Solarian compiles it without that flag.

Both need git and a C compiler, which the Xcode Command Line Tools provide (`xcode-select --install`). A checkout does this while `pip` or `uv` is still installing. A prebuilt wheel does it the first time Solarian is imported, once PyTorch is installed for `xformers`.

### Linux (Ubuntu / Debian)

Make sure you have build tooling and CUDA (if you intend to run policies on a GPU):

```bash
sudo apt-get install build-essential cmake libusb-1.0-0
```

For real-time control, lower the kernel scheduler latency or run Solarian with `chrt`/`nice`. See the [Modules](/docs/modules) page for guidance on per-module rates.

### On the robot itself

Robot-side installs typically only need the base package (no AI, no simulation):

```bash
pip install solarian
```

Then run `solarian run-robot` from the project directory. You do **not** need a GUI on the robot — Solarian's robot loop is headless.

## Verify the installation

```bash
python -c "import solarian; print(solarian.__name__, 'OK')"
solarian --help
```

You should see the Solarian CLI help with grouped command categories (Project, Robot, Controller, Recording, Training & Data, Utilities).
